# Установка

[О наборе](README.md) · [Примеры использования](EXAMPLES.md)

## Через Codex

1. Скачайте ZIP и распакуйте его. Откройте папку, в которой лежат `README.md`, `skills/` и `scripts/`. [Скачать с GitHub](https://github.com/da-p/presentation-skills/archive/refs/heads/main.zip)
2. Откройте эту папку в Codex и отправьте запрос ниже.
3. После установки попросите Codex проверить, что доступны все девять навыков.

```text
Установи набор навыков для презентаций из открытой папки.
Прочитай INSTALL.md. Установи все девять папок из skills/ как личные навыки
текущего пользователя, сохранив их соседство.
Если одноимённые навыки уже есть, сначала сравни версии и сохрани копию
для отката. При наличии моих локальных изменений покажи различия.
Проверь доступность девяти навыков после установки.
```

Установка копирует инструкции, справочники, примеры и вспомогательные инструменты.

## Редактура русского текста

Для работы с русским содержанием установите `redaktura` из открытого набора [Redaktura Skills](https://github.com/N1arko/redaktura-skills) Людмилы Сарычевой и Никиты Архипова. Достаточно этого навыка с его справочниками; весь набор пригодится, если вы также пишете статьи, посты и другие тексты.

Запрос для Codex:

```text
Установи навык redaktura со всеми его справочниками из открытого репозитория
https://github.com/N1arko/redaktura-skills для текущего пользователя.
Если он уже установлен, проверь его доступность без повторного копирования.
```

Проверка после установки:

```text
Найди установленный redaktura и открой его инструкцию.
Отредактируй фразу: «В рамках мероприятия будет осуществлено знакомство
участников с принципами работы музея». Объясни правку одним предложением.
```

В каталоге он может называться `redaktura` или иметь префикс плагина. Набор презентаций поддерживает оба способа установки. Без этой зависимости можно продолжать исследование и подготовку материалов, но редакторский этап останется незавершённым.

## Средства создания файлов

Для структуры, контента и критики достаточно доступа к исходным материалам и средств их чтения. Для готового PPTX нужны инструмент сборки и возможность проверить отображение. Для PDF — средство экспорта и просмотра. В Codex исполнитель сначала проверяет доступный комплект библиотек и профильные инструменты.

Установленный PowerPoint используется для проверки PPTX и экспорта, если он доступен. Если работа проверена в другой среде, исполнитель указывает её. Доступ к поиску, внешним источникам и генерации изображений определяется вашей средой; пакет их не подключает.

## Через командную строку

Этот способ предназначен для первой установки. Для инструментов набора используйте Python 3.9 или новее. Выполняйте команду из папки с файлом `INSTALL.md`.

macOS или Linux, стандартный каталог личных навыков Codex:

```sh
python3 scripts/install.py --target "$HOME/.codex/skills" --backup ".tmp/install-1"
```

Windows PowerShell с Python Launcher:

```powershell
py -3 scripts/install.py --target "$env:USERPROFILE\.codex\skills" --backup ".tmp\install-1"
```

Если в вашей среде принят другой каталог навыков, передайте его через `--target`. Параметр `--backup` задаёт новую, ещё не существующую папку: в ней сохраняются архив прежних файлов и контрольные суммы. Сохраните эту папку, если установка заменила предыдущую версию. Команда не требует пакетов из `requirements.txt`.

Скрипт проверяет наличие девяти навыков, копирование и архив для отката. Он не перезаписывает неизвестные одноимённые навыки. Замена старого одиночного `presentation-craft` поддерживается с предварительно проверенным списком контрольных сумм через `--expected-craft`. Для обновления уже установленного набора используйте порядок ниже.

## Проверка установки

В следующем запросе к Codex напишите:

```text
Проверь доступность навыков presentation-craft, presentation-structure,
presentation-content, presentation-visualize, presentation-design,
presentation-redesign, presentation-critique, presentation-polish
и presentation-build. Прочитай их названия и назначение из установленных
инструкций. Ничего не создавай.
```

Затем можно проверить отдельный навык без сборки файла:

```text
$presentation-structure
Предложи структуру из трёх слайдов о том, почему меняются времена года.
Аудитория — взрослые без специальной подготовки.
Результат — тезисы и назначение слайдов, без оформления.
```

Если навык не находится, проверьте, что `SKILL.md` расположен непосредственно в папке каждого навыка, а все девять папок лежат рядом в каталоге, который использует Codex. Нельзя установить только внешнюю папку `presentation-skills` вместо её содержимого `skills/`.

## Обновление и удаление

С версии 1.0.0 при первом вызове любого из девяти навыков в задаче Codex проверяет версию всего набора. Когда доступна новая версия, он покажет ссылку на ZIP и продолжит текущую задачу. Установка выполняется по вашей команде. Если вы установили набор до версии 1.0.0, скачайте свежий архив и обновитесь один раз по инструкции ниже. [Скачать с GitHub](https://github.com/da-p/presentation-skills/archive/refs/heads/main.zip)

При первой установке в папке, указанной в `--backup`, появляется `installed-files.json` со списком установленных файлов и их контрольными суммами. Сохраните его. Для обновления распакуйте новый пакет, укажите путь к этому списку и выберите новую папку для отката.

```sh
python3 scripts/install.py --expected-installed "/путь/к/предыдущей/установке/installed-files.json" --backup ".tmp/install-2"
```

Для нестандартной папки навыков добавьте тот же `--target`, что при установке. В PowerShell замените `python3` на `py -3`. Установщик сверит все девять навыков, сохранит прежнюю версию и перенесёт настройку библиотеки референсов. Если список утерян или в установленных файлах есть свои правки, сначала сравните их с предыдущим пакетом и решите, какие изменения сохранить.

При откате восстановите только папки этого набора из проверенной копии. Другие навыки в каталоге сохраняются. При удалении уберите девять папок набора после проверки, что в них нет ваших единственных исходников или правок. Созданные презентации в папках проектов удалять не нужно.

## Внешняя библиотека референсов

Собственную коллекцию можно начать с одной презентации командой «Собери удачные слайды в мою библиотеку». При первом сохранении набор создаст каталог и индекс. Для проверки изображений нужен Pillow. [Порядок отбора и выбор папки](skills/presentation-craft/references/collect-slides.md)

Банк Bonnie&Slide в поставку не входит и для начала работы не нужен. Набор может использовать другие доступные референсы и собственные примеры.

Если у вас есть совместимый каталог в формате JSONL, подключите его параметром `--library` при установке, через `PRESENTATION_PATTERN_LIBRARY` или локальный файл `presentation-craft/references/library.local.json` с полем `source`. Если у каталога ещё нет индекса SQLite, один раз выполните из папки распакованного набора:

```sh
python3 skills/presentation-craft/scripts/build_slide_pattern_index.py --file "/путь/к/библиотеке/каталог.jsonl"
```

Рядом с каталогом появятся индекс и справочник семейств. После изменения JSONL повторите команду. Для поиска без изменения настроек укажите `--file`, а при создании галереи передайте в `--image-root` папку, относительно которой записаны пути к изображениям в каталоге. Формат и порядок работы описаны в [справочнике поиска](skills/presentation-craft/references/slide-pattern-search.md). Личные пути и саму внешнюю библиотеку не включайте в распространяемый архив.

## Для разработчиков

При публикации изменений в `skills/` повышайте номер в `skills/presentation-craft/VERSION` в том же коммите. Проверка сверяет этот файл с веткой `main`. Формат номера — `MAJOR.MINOR.PATCH`.

Установщик и большинство вспомогательных команд используют стандартную библиотеку Python. Для проверки метаданных создайте `.venv` внутри папки пакета и установите `requirements.txt` в неё. Для работы с изображениями нужен Pillow; в Codex используйте доступную библиотеку среды, а в другой среде — проектную зависимость.

Из корня пакета:

```sh
python3 -m unittest discover -s tests
```

Основные проверки поиска и галереи используют небольшой учебный каталог и работают без банка. Для проверки результатов поиска на оригинальном каталоге Bonnie&Slide укажите путь к его JSONL через `PRESENTATION_PATTERN_LIBRARY`. Для проверок на настоящем файле задайте `PPTX_REVIEW_FIXTURE`. Без этих материалов соответствующие проверки пропускаются. Метаданные каждой папки можно проверить доступным `skill-creator/scripts/quick_validate.py`.

Исходники примера затмения используют `@oai/artifact-tool`; способ запуска и параметры находятся в [его описании](skills/presentation-craft/assets/eclipse-study/README.md).
