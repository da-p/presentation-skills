# Презентации — набор навыков для Codex

Девять навыков для работы над презентацией: от исследования и структуры до дизайна, редактируемого PowerPoint и PDF. Можно поручить весь процесс командой «Сделай презентацию» или вызвать отдельный навык — например, построить схему, оценить дизайн или исправить несколько слайдов.

Набор помогает объяснять сложное, выстраивать аргументы и находить выразительную подачу под конкретную аудиторию. Он подходит для деловых, учебных, исследовательских и публичных выступлений. В основе работы — содержание, источники и задача зрителя.

## Начать работу

После установки откройте папку проекта в Codex, приложите исходные материалы и напишите:

```text
$presentation-craft
Сделай презентацию о том, как музей может проводить занятия для школьников.
Аудитория — руководители школ. Цель — помочь выбрать программу для класса.
Используй материалы в папке проекта. Нужно около 8 слайдов
для самостоятельного чтения, редактируемый PPTX и PDF.
```

В запросе полезно назвать аудиторию, цель, способ просмотра и нужный результат. Приложите фактуру, данные и имеющиеся образцы. Если в проекте уже есть дизайн-система, набор использует её; при неясном статусе документа уточнит выбор.

## Какие навыки входят

| Навык | Команда | Что получается |
|---|---|---|
| Сделай презентацию | `$presentation-craft` | Полный маршрут до готовых файлов |
| Структура | `$presentation-structure` | Главный тезис, ход аргументации, назначение слайдов и источники |
| Контент | `$presentation-content` | Тексты, доказательства, данные, примеры и подписи |
| Наглядное объяснение | `$presentation-visualize` | Таблица, схема, график, карта или другое объяснение отношений |
| Дизайн с нуля | `$presentation-design` | Художественная концепция, графика и опорные слайды |
| Редизайн | `$presentation-redesign` | Новое оформление готовой презентации с сохранением её содержания |
| Критика | `$presentation-critique` | Предметные замечания и способы исправления, без изменения файлов |
| Доводка | `$presentation-polish` | Точечные исправления в принятом оформлении |
| Сборка и выпуск | `$presentation-build` | Презентация по готовому содержанию и дизайну, проверка и экспорт |

Каждый навык можно вызвать отдельно. Общая команда выбирает нужные этапы и передаёт результаты между ними. Готовые тексты, найденные источники и принятые решения используются повторно.

## Как строится работа

Обычный маршрут: **структура → контент → наглядное объяснение → дизайн → сборка**. Наглядное объяснение подключается там, где нужно показать отношения или данные. Редизайн начинается с разбора исходного файла, а небольшая правка сразу попадает в доводку.

По умолчанию действует **авторский режим**. При свободном оформлении он предусматривает три разных направления на реальном содержании, два–три опорных слайда и отдельную критику содержания и дизайна. Если стиль уже задан, работа идёт в его рамках.

Для короткого прохода добавьте к запросу «в быстром режиме». Тогда разрабатывается одно направление и один сложный опорный слайд. Проверка фактов, сохранность содержания и исправность файла остаются обязательными. Независимая критика требует среды, поддерживающей отдельного проверяющего; самопроверка обозначается как самопроверка.

Во время работы набор:

- сохраняет существенные факты, связи и утверждённые решения;
- применяет найденную действующую дизайн-систему проекта;
- проектирует изображения вместе с текстом и пространством слайда;
- использует колонтитулы с понятной функцией;
- сохраняет текст, числа, таблицы и обычные схемы редактируемыми;
- при локальной правке проверяет затронутые слайды и зависимые элементы.

## Обновления

При первом вызове навыка в задаче Codex сверяет версию набора с GitHub. Если вышла новая версия, он покажет ссылку на ZIP и продолжит работу. Проверка доступна с версии 1.0.0. [Как обновить установленный набор](INSTALL.md#обновление-и-удаление)

## Что понадобится

Основная среда — **Codex** с доступом к файлам проекта. Для подготовки русского текста нужен навык `redaktura` из [Redaktura Skills](https://github.com/N1arko/redaktura-skills) Людмилы Сарычевой и Никиты Архипова. Он устанавливается отдельно.

Для выпуска PPTX и PDF среде нужны средства создания, просмотра и экспорта презентаций. Сам набор содержит инструкции и вспомогательные инструменты; программы для работы с презентациями в него не входят. Зависимости и варианты установки описаны в [инструкции](INSTALL.md).

## Своя библиотека слайдов

Попросите «Собери удачные слайды из этой презентации» или «Сохрани слайды 3 и 7 в мою библиотеку». Набор сохранит изображения и опишет, для какой задачи пригодится каждый приём. Чтобы пополнять библиотеку при следующих выпусках, достаточно один раз сказать «В этом проекте собирай удачные слайды после выпуска». [Как устроен отбор](skills/presentation-craft/references/collect-slides.md)

## Примеры и устройство пакета

В [примерах использования](EXAMPLES.md) для каждого навыка есть входные материалы, готовый запрос и ожидаемый результат. Внутри пакета также находятся пять смысловых преобразований на вымышленных данных и разбор затмения с тремя направлениями и воспроизводимыми исходниками.

`skills/` содержит девять папок навыков. Общие методы, примеры и инструменты находятся у `presentation-craft`; при установке все девять папок должны оставаться соседними. `scripts/install.py` устанавливает набор, `tests/` проверяет вспомогательные инструменты. Актуальная версия хранится в ветке `main`.

Для проверки инструментов из папки пакета запустите `python3 -m unittest discover -s tests`. Для проверки метаданных используйте локальную `.venv` с зависимостями из `requirements.txt`; для операций с изображениями нужен Pillow. Тесты внешнего каталога и реального PPTX используют отдельно заданные материалы. Подробности — в [инструкции по установке](INSTALL.md#для-разработчиков).
