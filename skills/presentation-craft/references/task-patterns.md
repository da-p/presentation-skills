# Маршруты по задаче

Общий выбор выполняет [Сделай презентацию](../SKILL.md). Самостоятельные процедуры: [структура](../../presentation-structure/SKILL.md), [контент](../../presentation-content/SKILL.md), [дизайн](../../presentation-design/SKILL.md), [редизайн](../../presentation-redesign/SKILL.md), [доводка](../../presentation-polish/SKILL.md).

## Поиск объяснения и визуального направления

Сначала выбирается способ показать отношения по [методам объяснения](explanation-methods.md), затем художественная подача по [методу концепции](design-methods.md). Выбранный рабочий прототип развивается в опорный слайд. Смысловые эскизы не создаются повторно на этапе дизайна.

## Редизайн с сохранением содержания

Используй [редизайн](../../presentation-redesign/SKILL.md). Сохрани существенные факты, связи, изображения и ручные правки. Новая подача должна сохранить или улучшить объясняющую функцию прежних решений. Оценка содержания и дизайна раздельная.
