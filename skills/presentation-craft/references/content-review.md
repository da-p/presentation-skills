# Проверка содержания

Подготовкой занимается [Контент](../../presentation-content/SKILL.md). Независимую проверку выполняет [Критика](../../presentation-critique/SKILL.md) по разделу «Содержание» в [критериях](critique-methods.md).

В авторском маршруте достаточно одного отдельного просмотра до дизайна с подтверждением исправленного. После сборки проверяется сохранность содержания в готовом файле; полный редакторский цикл повторяется лишь при содержательном изменении. Состояние результата хранится по [общему порядку](handoff.md).
