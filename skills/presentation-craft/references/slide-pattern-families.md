# Семейства приёмов

Выбери семейство по тому, что читателю предстоит увидеть или сравнить. Поиск по семейству доступен с любой подключённой библиотекой. Один референс может подходить для нескольких задач.

| Задача | Принцип | Код для поиска |
|---|---|---|
| Сопоставление вариантов | Общие основания сравнения, одинаковая структура вариантов. | `comparison` |
| До и после | Два состояния и явно обозначенное изменение. | `change` |
| Изменение во времени | Временная ось и направление изменения показателя. | `trend` |
| Последовательность действий | Порядок шагов и переходы между ними. | `sequence` |
| Иерархия и ветвление | Уровни, родительские элементы и подчинение. | `hierarchy` |
| Сеть взаимосвязей | Узлы и связи, не обязательно образующие дерево. | `network` |
| Целое и части | Доли, состав и отношение элементов к общему. | `parts` |
| Повторение единиц | Количество через повтор одинаковых элементов или групп. | `units` |
| Число как главный акцент | Ключевой показатель с контекстом и пояснением. | `metric` |
| Ранжирование | Упорядоченные значения и различия между позициями. | `ranking` |
| Пространство и расположение | Карта, план или привязка к месту. | `location` |
| Матрица критериев | Пересечение двух признаков или систематическая таблица. | `matrix` |
| Крупный предметный образ | Один заметный предмет или фотография и связанный тезис. | `hero` |
| Типографический акцент | Размер и характер текста создают главный образ. | `type` |
| Изображение и текст рядом | Две согласованные зоны с разными ролями. | `split` |
| Наложение и вырезанный объект | Перекрытие создаёт глубину и объединяет текст с изображением. | `layers` |
| Серия объектов | Несколько изображений или объектов в общей системе. | `gallery` |
| Выделение одного элемента | Один элемент получает преимущество на фоне остальных. | `focus` |
| Открытие темы | Короткий заголовок и выразительный вход в тему. | `cover` |
| Тезис и доказательство | Утверждение подкреплено наблюдением, данными или примером. | `evidence` |

Команда `python3 scripts/search_slide_patterns.py --families` покажет, сколько примеров нашлось в каждом семействе вашей библиотеки, и выведет карточки для первого просмотра.
