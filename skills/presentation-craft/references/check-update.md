# Проверка обновления набора

Один раз на задачу запусти [check_update.py](../scripts/check_update.py) через Python 3. Возьми абсолютный путь из той же копии `presentation-craft`, к которой относится этот справочник. При переходах между навыками проверку не повторяй.

- При `update_available` сообщи пользователю одним предложением, какая версия вышла и какая установлена, и приложи [ссылку на ZIP](https://github.com/da-p/presentation-skills/archive/refs/heads/main.zip). Сообщи об одной и той же версии один раз за разговор, если пользователь не попросил проверить ещё раз.
- При `no_update` продолжай работу. При `unavailable` или отсутствии Python можно сверить локальный [VERSION](../VERSION) с [VERSION на GitHub](https://github.com/da-p/presentation-skills/blob/main/skills/presentation-craft/VERSION) через доступный инструмент чтения. Сравни три числовых компонента по порядку. Если версию подтвердить не удалось, продолжай работу. По прямому запросу на проверку сообщи её результат.

Предложение скачать ZIP не требует ответа. Продолжай текущую задачу. Скачивай или устанавливай обновление только по отдельной просьбе пользователя. Для установки используй [инструкцию](https://github.com/da-p/presentation-skills/blob/main/INSTALL.md#обновление-и-удаление).
