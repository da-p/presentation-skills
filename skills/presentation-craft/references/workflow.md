# Совместимость прежних проектов

Новые задачи используют [компактное состояние этапов](handoff.md). Скрипты `presentation_context.py` и `presentation_workflow.py` сохранены без изменения прежнего формата для восстановления старых планов и воспроизводимости испытаний. Их `prepare`, `packet`, `record`, `status` и `check` не являются обязательной процедурой нового набора. Справку по прежним аргументам получай через `--help`.

Не переносите старые положительные вердикты на изменённые материалы. Не мигрируйте все проекты автоматически. Новый `presentation_pipeline.py` дополняет существующий план; чтение само по себе ничего не меняет.
