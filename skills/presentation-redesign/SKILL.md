# Редизайн готовой презентации

При первом вызове навыка набора в этой задаче [проверь обновление](../presentation-craft/references/check-update.md), затем продолжай работу.

**Вход:** актуальная презентация, замечания и границы изменения текста. **Результат:** обновлённый файл с сохранением содержания в пределах задачи.

1. Найди последнюю версию с ручными правками. Посмотри все слайды, извлеки тексты, данные, заметки и связи. Сложные схемы сверяй по изображениям. Старый генератор сначала сопоставь с актуальным файлом.
2. В [плане](../presentation-craft/references/handoff.md) зафиксируй сохраняемые факты, формулировки по требованию, структуру, схемы, изображения и удачные решения. Для проблемы назови причину и наблюдаемый результат исправления.
3. По умолчанию содержание сохраняется. Не запускай исследование и переписывание всей истории. Содержательное противоречие покажи отдельно; меняй только разрешённое.
4. При необходимости нового способа объяснить тот же смысл подключи [визуализацию](../presentation-visualize/SKILL.md). Для оформления используй [дизайн](../presentation-design/SKILL.md), не дублируя его процедуры.
5. Передай исходники в [сборку](../presentation-build/SKILL.md). Сравни с актуальным оригиналом: смысл и данные отдельно от художественного качества. Полезная схема может измениться, но её объясняющая функция должна сохраниться или улучшиться.

Новая концепция может полностью заменить оформление в разрешённых пределах. Найденная действующая дизайн-система проекта сохраняет силу; запрос на редизайн сам по себе не отменяет её цвета и типографику. Просьба «сохранить стиль и поправить» относится к доводке. Покажи существенное в сравнении «до/после». Не заменяй оригинал при запросе отдельной версии.
