# Доводка презентации

**Вход:** актуальный файл и изменения. **Результат:** исправленный файл с сохранением всего вне задачи.

1. Сверь актуальную презентацию с исходниками сборки. Не перезаписывай ручные изменения старым генератором. Найди принятый дизайн, нужные источники и затронутые слайды.
2. Исправь заданное. Число проверь по источнику, обнови зависимые подписи, итог или масштаб. Исправление подписи не требует новых референсов и концепций.
3. Отрендери изменённые слайды и проверь переносы, группировку, соседние элементы. При общей правке шрифта, сетки или экспорта просмотри всю затронутую область.
4. Выполни заключительную часть [сборки](../presentation-build/SKILL.md): сохранность, экспорт и проверка выдаваемого файла. Для локальной правки достаточно самопроверки.

Используй существующий [план](../presentation-craft/references/handoff.md), если он есть. Ради одного знака план не создаётся. Смена концепции относится к редизайну; не расширяй задачу самостоятельно.
